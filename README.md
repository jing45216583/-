# 词流 WordFlow

一个可以**导入自己词库**的手机端背单词应用。纯前端、零依赖、零构建，进度存在本机浏览器里。

每天像「不背单词 / 百词斩」那样：先学一批新词，再把到期该复习的词过一遍；答错的词当天再考一次，间隔按 SM-2 改良算法自动往后推。

- 手机尺寸（390×844）下的实机截图：[首页](shots/home.png) · [单词卡](shots/study.png) · [复习评分](shots/study-front.png) · [统计](shots/stats.png) · [深色模式](shots/dark-home.png)
- 想直接试：双击 `index.html` 就能用（里面自带一份 59 词的示例词库）

## 一、四种打开方式

| 方式 | 怎么做 | 说明 |
| --- | --- | --- |
| 电脑上试用 | 双击 `index.html` | 无需服务器。功能全在，但浏览器不允许 `file://` 注册 Service Worker，所以没有离线缓存 |
| 手机连电脑局域网 | 在 `wordflow` 目录跑 `python -m http.server 8000`，手机浏览器访问 `http://<电脑局域网IP>:8000` | 手机和电脑要同一个 Wi-Fi，电脑得开着 |
| **不联网、电脑不开机** | 把 `wordflow-standalone.html`（单文件版）传到手机，用浏览器打开 | 样式、脚本、词库全在这一个 133KB 的文件里，**不需要服务器、不需要网**。生成命令见第七节 |
| 最稳：装成 PWA | 把整个 `wordflow` 目录传到 GitHub Pages / Vercel / Netlify 等免费静态托管，手机浏览器打开后「添加到主屏幕」 | 需要联网一次；装好后全屏无地址栏，Service Worker 缓存了全部文件，**之后断网也能背**，且不怕文件被微信清理 |

> 添加到主屏幕后是一个独立图标，交互和原生 App 基本一致（iOS 用 Safari 添加，Android 用 Chrome）。

### 单文件版怎么用（离线 + 电脑关机）

1. 在 `wordflow` 目录跑一次 `python tools/build_standalone.py`，得到 `wordflow-standalone.html`。
2. 传到手机：微信「文件传输助手」发给自己 → 手机上点开 → 右上角「用其他应用打开 / 用浏览器打开」；或用数据线拷到 `Downloads`。
3. 之后从浏览器的下载记录 / 文件管理里点这个文件就能打开，全程不用网。
4. **重要**：进度存在这个浏览器给「本地文件」分配的存储里，清理浏览器数据、换浏览器、把文件改名或移动位置都可能丢，`设置 → 导出备份` 存一份 JSON（微信收藏/网盘）比较保险。

Android 上一般都没问题；iOS 的「文件」App 打开本地 html 限制较多，建议走托管 + 添加到主屏幕那条路。

## 二、导入自己的词库

「词库」页 → **＋ 导入词库** → 粘贴内容或点选文件。识别到的单词数、格式（CSV/TSV/纯文本/JSON）、前三个词的预览都会显示出来，确认无误再点导入。

### 支持的内容格式

| 格式 | 例子 |
| --- | --- |
| CSV / TSV（可带表头） | `word,phonetic,meaning,example`<br>`abandon,/əˈbændən/,v. 抛弃；放弃,He abandoned the plan.` |
| 竖线 / 分号 / 全角逗号分隔 | `abandon|v. 抛弃；放弃` |
| 纯文本，每行「单词 释义」 | `abandon v. 抛弃；放弃`（空格或 Tab 都行） |
| 只有单词，一列 | `abandon` |
| JSON 对象数组 | `[{"word":"abandon","meaning":"v. 抛弃"}]` |
| JSON 字符串数组 | `["abandon\tv. 抛弃", "absorb\tv. 吸收"]` |

### 规则细节

- **表头自动识别**，中英文都认：`word / 单词 / 词汇 / term` → 单词；`phonetic / 音标 / ipa / 发音` → 音标；`meaning / 释义 / 翻译 / 中文 / 解释 / definition` → 释义；`example / 例句 / 句子` → 例句；`tags / 标签 / 分类` → 标签。
- 没有表头时按默认列序解析：**单词, 音标, 释义, 例句**。音标列会靠 IPA 符号自动猜，猜不到就按位置。
- 至少要有单词；音标、例句可以完全没有，只写「单词 + 释义」即可。
- 空行、纯标点行、`1.` 这类序号会被跳过；加了序号的行也能解析（`1. abandon v. 放弃` → 单词 `abandon`）。
- 按单词**不分大小写去重**，重复的自动跳过并在提示里报数。
- 文件需要是 **UTF-8** 编码。Excel 导出请选「CSV UTF-8」，否则中文释义会变乱码（应用检测到 `` 会提醒）。
- 导入后可以在「词库 → ⋯ → 查看单词」里逐条改释义、删词、重置学习进度。

### 现成的词库：`wordbanks/`

`wordbanks/` 里放了从课件整理出来的成品，直接「＋ 导入词库 → 点选文件」即可：

| 文件 | 卡数 | 方向 | 适合 |
| --- | --- | --- | --- |
| `有机命名.csv` | 68 | 中文 → 英文 | 看到官能团/规则，回想英文词头词尾 |
| `有机命名-反向.csv` | 66 | 英文 → 中文 | 看到 `-oic acid`、`meth-`，回想中文含义 |

来源是《有机化学（上）》命名课件的 44 行官能团对照表 + 10 条命名规则，两条词库互补，建议先导入正向、学完再导入反向自测。
课件里两处笔误已在卡片中按标准写法修正（`choloride` → `chloride`；羧基词头 `carbonyl-` → `carboxy-`、词尾 `-onic acid` → `-oic acid`），课件原说法保留在例句里对照。

**手机上一键导入**：「词库 → ＋ 导入词库」面板顶部就有「现成词库，点一下直接填入」，点一下自动填好词库名和全部内容，再点「导入」即可，不用把 CSV 传进手机。

## 三、每天怎么用

1. 首页看「今日计划」：新学 `已完成/今日额度`、复习 `已完成/到期数`、预计用时。
2. 点 **开始学习**。
3. 先看单词（可点喇叭朗读）→ 点卡片或「显示释义」翻面 → 四档评分：

| 评分 | 按键 | 含义 | 间隔变化 |
| --- | --- | --- | --- |
| 忘记 | 1 | 完全想不起来 | 新词 1 分钟后再出现；复习词间隔 ×0.3，重新进入短时重学 |
| 模糊 | 2 | 想起来了但很费劲 | 新词 6 分钟后；复习词间隔 ×1.15 |
| 认识 | 3 | 记得，正常难度 | 新词 → 明天；复习词 间隔 ×ease |
| 简单 | 4 | 太简单了 | 新词 → 4 天后；复习词 间隔 ×ease×1.35，且 ease +0.1 |

4. 评分为「忘记 / 模糊」的词会**插回队列再考一次**（同一个词一次会话最多回炉 2 次），这也是「当天加固」的来源。
5. 中途退出不要紧，进度和队列都存着，首页按钮会变成「继续学习 · 剩余 N」。
6. 学完出现完成页：本轮新学/复习/记忆率，可以直接「再学一轮」。

## 四、算法说明

改良版 SM-2，每张卡有两个参数：`ease`（难度系数，初始 2.5）和 `ivl`（当前间隔天数，初始 0）。

- **新词阶段**（learning）：忘记 +1min、模糊 +6min，两个都答对才毕业；毕业间隔 1 天（评「简单」直接 4 天）。
- **复习阶段**（review）：`认识` → `ivl × ease`；`简单` → `ivl × (ease+0.1) × 1.35`；`模糊` → `ivl × 1.15` 且 `ease − 0.15`；`忘记` → `ivl × 0.3` 且 `ease − 0.2`，回到 short relearning（+10 分钟），并记一次遗忘。
- **边界**：`ease` 限制在 1.3–3.2，间隔限制在 1–3650 天，避免一张卡被推到几年后或崩到 0 天。
- **一天的分界线是本地凌晨 4 点**：凌晨 2 点背的单词算「昨天」，作息乱也不会断签。
- **每日额度**：默认新学 20、复习 150，可在设置里改；新词和复习按比例交错排进队列，避免一口气背完 20 个新词后集中轰炸。

## 五、数据与备份

- 所有词库、进度、统计都存在浏览器的 `localStorage`（键名 `wordflow.v1`），**不上传任何服务器**，换设备/换浏览器不会同步。
- **设置 → 导出备份** 会下载一个 JSON（含全部词库 + 学习进度 + 每日统计）；**导入备份** 支持合并或覆盖。
- 换手机、清理浏览器数据之前请先导出，这是唯一的数据出口。
- 「清空全部数据」不可恢复。

## 七、开发与测试

没有构建步骤、没有 npm 依赖，改完文件刷新页面即可（脚本是 classic script，不是 ES module，所以 `file://` 直接打开也能跑）。

```bash
node tools/test.js      # 算法 + 词库解析的单元测试（任意现代 Node）
node tools/smoke.js     # 真浏览器里跑：导入、学习、评分、刷新持久化（需 Node ≥ 22）
node tools/verify_wordbank.js   # 化学生词库：解析、渲染、长释义溢出、一键导入
python tools/build_standalone.py && node tools/verify_standalone.js  # 单文件版打包 + 离线校验
python tools/gen_assets.py   # 重新生成图标和示例词库（需要 Pillow）
python tools/build_wordbank.py  # 从课件 xlsx 重新生成词库（需要 openpyxl）
```

`tools/smoke.js` 会自己拉起无头 Edge，通过 CDP 把设备设为 390×844 / DPR 2，所以断言和截图用的都是真手机的视口。

> 改动 `css/`、`js/`、`index.html` 之后记得重跑一次 `python tools/build_standalone.py`，不然单文件版还是旧的。

## 八、已知限制

- 发音走系统 TTS（`speechSynthesis`），音质取决于手机的语音包；iOS 上需要先有一次用户交互才允许出声。设置里可以选美音/英音和语速。
- 单次会话不做长按编辑，改词请到「词库 → 查看单词」。
- 词库超过几千词时，单词列表做了分批渲染（每次 200 条，可「显示更多」），首页统计仍是一次性计算。
- 数据存在浏览器里，清理站点数据/无痕模式会丢，请定期导出备份。
- 单文件版用 `file://` 打开：没有 Service Worker / 图标，也不显示「添加到主屏幕」。如果浏览器连本地存储都禁用了，首页顶部会出现橙色提示条，这时数据只在内存里，务必先导出备份。
